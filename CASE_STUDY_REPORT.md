
# Data Structures Case Study Report

## Case Study 1: E-commerce Product Sorting

### Problem Statement
E-commerce websites contain many products with different
prices. Sorting products by price helps users find cheaper
or more expensive products easily.

### Algorithm
Merge Sort using Divide and Conquer.

### Working
1. Accept product names and prices.
2. Divide the list into two halves.
3. Sort the smaller lists.
4. Merge the lists in ascending price order.
5. Display the sorted products.

### Time Complexity
O(n log n)

### Applications
- Online shopping websites
- Product price comparison
- Inventory management

### Conclusion
Merge Sort sorts products efficiently by price.

## Case Study 2: Calendar Event Scheduling

### Problem Statement
People have several events and need to select events
without overlapping.

### Algorithm
Activity Selection using the Greedy Strategy.

### Working
1. Accept event names, start times, and end times.
2. Sort events by ending time.
3. Select an event that does not overlap with the
   previously selected event.
4. Display the selected events.

### Time Complexity
O(n log n)

### Applications
- Meeting scheduling
- Classroom timetables
- Event planning

### Conclusion
The Greedy Strategy selects the maximum number of
compatible events for the given activity-selection problem.
