# Data Structures Case Studies

This repository contains two Data Structures case studies
implemented using Python.

## Case Study 1: E-commerce Product Sorting

- **Algorithm:** Merge Sort
- **Strategy:** Divide and Conquer
- **Purpose:** Sort products from lowest price to highest price.
- **File:** `product_sorting.py`

## Case Study 2: Calendar Event Scheduling

- **Algorithm:** Activity Selection
- **Strategy:** Greedy Method
- **Purpose:** Select the maximum number of non-overlapping events.
- **File:** `calendar_greedy.py`

Note: The calendar project is a simplified educational
scheduler. It does not connect to the actual Google Calendar.

## Technologies Used

- Python 3
- Data Structures and Algorithms

## How to Run

Run the product sorting program:

```bash
python product_sorting.py
```

Run the calendar scheduling program:

```bash
python calendar_greedy.py
```

## Conclusion

These case studies demonstrate how Merge Sort and the
Greedy Strategy can solve practical problems using Python.
